Opportunities Debug Tool

Instructions

1. Open browser developer tools (F12)

2. Go to Console tab

3. Navigate to your app and check the console logs

4. Look for logs starting with 🔍, ⚠️, or ❌

Expected API Response Structure

The v2 API should return one of these structures:

Option 1: Direct Array

[ { "id": 1, "title": "Opportunity Name", "status": "Enrolled" // or "Not Enrolled" } ]

Option 2: Nested Object

{ "opportunities": [ { "id": 1, "title": "Opportunity Name", "status": "Enrolled" // or "Not Enrolled" } ] }

Common Issues

  • Status field missing: API might return "enrollment_status" instead of "status"
  • Boolean instead of string: API might return "is_enrolled": true instead of "status": "Enrolled"
  • Different field names: Check if title field is "name" instead of "title"
  • API not implemented: v2 endpoint might not be ready, falling back to v1

Debug Steps

  1. Check console for "🔍 V2 API Response:" - this shows the raw API response
  2. Check "🔍 Processing opportunity:" - this shows each opportunity being processed
  3. Check "🔍 Mapped opportunity:" - this shows the final mapped result
  4. Check "🔍 Checking enrollment status:" - this shows the enrollment check logic
  5. If you see "❌ V2 API failed" - the v2 endpoint is not working, falling back to v1
